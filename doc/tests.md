# Tests

The plugin is tested with **PHPUnit** (unit, functional, integration), **Behat** (UI),
**PHPStan** (level max) and **ECS** (coding standard). The test application lives in
`tests/TestApplication` and runs on top of `sylius/test-application`.

## Docker (recommended)

```bash
make init            # Containers + composer install + frontend build
make up / make down  # Start / stop the containers
make php-shell       # Shell in the PHP container
make database-init   # Create the database and run migrations
make load-fixtures   # Load Sylius fixtures
```

Then:

```bash
make phpunit         # PHPUnit
make behat           # Behat
make phpstan         # PHPStan
make ecs             # Coding standard
```

> The `nginx` service binds port 80. If that port is taken on your machine, change it in
> `compose.override.yml` — the file is generated by `make init` from `compose.override.dist.yml`
> and is not tracked by git.

## Running the tools directly

```bash
# PHPUnit — suites: unit, functional, integration, non-unit, all
vendor/bin/phpunit --testsuite unit
vendor/bin/phpunit

# Static analysis & coding standard
vendor/bin/phpstan analyse -c phpstan.neon -l max src/
vendor/bin/ecs check src tests           # add --fix to autofix

# Container linting & composer
vendor/bin/console lint:container
composer validate --strict
```

Database credentials are configured in `tests/TestApplication/.env` (dev) and
`tests/TestApplication/.env.test` (test). Inside Docker they are overridden by the
environment declared in `compose.override.yml`.

## Behat

Non-JavaScript scenarios run against the kernel and need no web server:

```bash
vendor/bin/behat --strict --tags="~@javascript"
```

They do need the frontend build, since the admin layout renders the Webpack entrypoints:

```bash
docker compose run --rm nodejs
```
